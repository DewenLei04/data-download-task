# Download research data

Start at ${site_url}.

Collect two inputs for separate analyses: the TLC Trip Record Data January 2023 green taxi Parquet extract and the Historical Data Toronto International A 2023 daily climate CSV. The transport and climate records refer to different cities; no geographic join is requested.

Save the original downloaded files in `/home/user/output/`, keeping the filenames offered by the website. Do not edit or re-export the contents. The browser is configured to download into this directory. Additional files do not affect the score; each requested file receives equal credit.

The website contains synthetic research fixtures, not official observations.
