# Download research data

Start at ${site_url}.

Find the Airlines dataset in the CORGIS JSON Datasets collection. Download the JSON file containing monthly flight statistics for 29 US airports for January through December 2015.

Use the visible browser and the website's page controls to find and download the files. Do not use a terminal, scripts, or direct HTTP requests to obtain the data. Save the original downloaded files in `/home/user/output/`, keeping the filenames offered by the website. Do not edit or re-export the contents. The browser is configured to download into this directory. Additional files do not affect the score; each requested file receives equal credit.

The website contains synthetic research fixtures, not official observations.
